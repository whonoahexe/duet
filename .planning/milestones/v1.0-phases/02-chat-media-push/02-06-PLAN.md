## Gaps closed

From `.planning/phases/02-chat-media-push/02-UAT.md` `## Gaps` (diagnosed):

- **G-02-42** (UAT test 42, major): "it should auto scroll down when a msg is sent". Root cause: no code path scrolls to the end on a local send. The only scrollToEnd caller is ScrollFollower's OPEN_CHAT_EVENT handler, and Composer is rendered outside MessageScrollerProvider. Own messages relied on the primitive's following-bottom mode, which is off when scrolled up and is also switched off by a non-scrolling wheel/touch at the bottom. Debug session: `.planning/debug/no-autoscroll-on-send.md`.
- **G-02-7** (UAT test 7, major): "notifications are not working on iphone but pass on android". Root cause: every duet push carries a Topic header (`duet-chat` / `duet-test`), and since about mid-September 2026 web.push.apple.com answers any Topic header with 400 BadWebPushTopic. FCM accepts it, which is why the Pixel works. The reason was hidden because push_failed drops WebPushError.body. Debug session: `.planning/debug/iphone-push-not-arriving.md`.
