Crop for images before sending and for profile photos (she asked for it). Today profile photos are centre-cropped automatically on the server (server/src/media/image.ts, fit cover / position centre) and images are sent uncropped. Decided 2026-10-21: images only (no video trimming), no rotate. One shared crop screen used in two places: (1) Profile photo — after choosing a photo, a fixed circle frame, drag + pinch to position, Save; replaces the automatic centre crop. (2) Sending — a Crop button on each image in the send preview drawer (each image cropped on its own when sending several), with Free and Square aspect options. How: the phone only picks the rectangle; it uploads the full-quality original plus the crop rect (normalised 0–1, relative to the EXIF-rotated image), and the server applies it with sharp (rotate() first, then extract) before making thumbnails/variants — no canvas re-encode, so no quality loss, and iPhone HEIC keeps going through the existing server path. The stored original is the cropped image, so the viewer, save button and gallery all show the crop. Preset constraint: shadcn has no cropper, so hand-write it (pointer events for drag/pinch, crop box + dimmed overlay, preset tokens and components for the buttons/toggle) rather than react-easy-crop, which brings its own look.
