## Phase Goal

> ROADMAP Phase 1 Goal (verbatim; not in user-story format): "Both of us can open duet at its own HTTPS address, log in with a password, and install it to our home screens, and the self-hosted SFU is proven to carry media from a phone on cellular."

This plan is the first half of the parallel, user-gated ops track: the SFU and coturn up on this machine and publicly addressable (INFR-03). 01-05 proves media over cellular.

<objective>
Bring the self-hosted media plane up at home:
1. One sitting with the user collects every human-only input for the phase: the CGNAT readout, the router configuration, the Cloudflare and GitHub tokens, and the account seed file.
2. Claude then creates the sfu/turn DNS-only records, issues DNS-01 certificates, and runs the SFU + coturn + nginx-sni stack as its own compose project, with every config value taken from the research.
3. Claude makes it survive certificate expiry, IP changes and reboots.

Purpose: INFR-03. The decisions this implements are D-02 (sfu./turn. as grey-cloud A records), D-13 (Claude automates everything; the user gets an exact checklist), D-14 (a separate compose stack) and D-15 (a CGNAT result pauses the track and asks).
Output: the ops/sfu stack, its scripts, NETWORK.md and README.md.

Ordering note: the first task is a human-action gate, not the tracer. Nothing can be built before it: the SFU image is private, DNS and certificates need the user's token, and D-15 requires the CGNAT pause first. The tracer (Task 2) is the first implementation task.
</objective>

| Boundary | Description |
|----------|-------------|
| Internet -> router -> box :443 / :44444-5 | Untrusted WebRTC, TURN and WSS traffic enters the home network |
