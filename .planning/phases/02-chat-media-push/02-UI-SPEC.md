# Phase 02 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Sources: `02-CONTEXT.md` (D-01..D-16 and the discretion list), `01-CONTEXT.md` (D-08..D-11), `.claude/CLAUDE.md` (locked preset), and the live codebase (`web/components.json`, `web/app/globals.css`, `web/components/app/shell.tsx`, `web/components/ui/*`). This phase has no RESEARCH.md. Every value below is either taken from those sources or is a default chosen under "Claude's Discretion" and marked **(default)**.

**Hard rule:** every component comes from `npx shadcn add <name>` (run in `web/`) with the `base-luma` style. Icons come only from `@phosphor-icons/react`. Colors come only from the preset CSS variables in `web/app/globals.css`. No new CSS variables, palettes, fonts, lucide, Radix, or emoji-picker libraries. Tailwind utility classes on top of preset components (for example `text-base` on `BubbleContent`) are allowed. Editing `globals.css` tokens is not.

## Spacing Scale

Declared values (all multiples of 4, Tailwind units in brackets):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`1`) | Gap between consecutive bubbles in one sender group, gap between album grid tiles, icon-to-text gap inside the status line |
| sm | 8px (`2`) | Gap between composer controls, gap inside the reaction row, quote-block inner padding, header avatar-to-name gap. **Exception:** the Phase 1 header keeps its `gap-3` (12px) unchanged, because it is inherited and not new Phase 2 spacing. |
| md | 16px (`4`) | Message list horizontal padding (`px-4`), gap between sender groups, composer horizontal padding, drawer body padding |
| lg | 24px (`6`) | Vertical space around day/time markers, onboarding card padding, onboarding step list gap |
| xl | 32px (`8`) | Top padding above the first message and below the "beginning of conversation" marker |
| 2xl | 48px (`12`) | Onboarding guide vertical spacing between the title block and the steps |
| 3xl | 64px (`16`) | Full-screen Add to Home Screen guide top/bottom padding (plus safe-area insets) |

Layout rules:
- Header keeps the Phase 1 shape: `h-14` (56px) plus `pt-[env(safe-area-inset-top)]`, sticky, `border-b`.
- Composer is pinned to the bottom: `border-t bg-background px-4 py-2` (16px/8px) plus `pb-[max(8px,env(safe-area-inset-bottom))]`.
- Override `MessageScrollerContent`'s preset `gap-8` with `gap-4` (16px between scroller items). One scroller item is one sender group or one marker.
- Inside a sender group use `BubbleGroup className="gap-1"` (4px). A sender group is consecutive messages from the same person with less than 2 minutes between them **(default)**.
- A bubble that carries a `BubbleReactions` chip gets `mb-4` (16px) so the chip does not overlap the next bubble.
- Bubble max width stays at the preset's `max-w-[80%]`. Album and voice-note bubbles use a fixed width of `w-72` (288px), capped at 80%.

Exceptions:
- Touch targets: composer buttons (attach, mic, send) and the voice-note play button are `size-11` (44px) to meet the 44px minimum on phones. Header and drawer buttons keep the preset sizes (`icon` 36px, `default` h-9).
- Preset component internals (for example `BubbleContent px-3.5 py-2.5`, `rounded-3xl`, button heights) are used unchanged and are not re-tokenized.
- Waveform bars are drawn SVG graphics, not layout spacing: 40 bars, 2px wide, 2px apart, 4px minimum height, 32px maximum height.
- Swipe-to-reply thresholds are gesture distances, not layout spacing: 8px dead zone, 56px trigger, 72px maximum travel.

## Color

Preset dark tokens, converted from OKLCH in `web/app/globals.css` `.dark`. Use the CSS variables or Tailwind token classes, never the hex values.

| Role | Token | Value (≈hex) | Usage |
|------|-------|--------------|-------|
| Dominant (60%) | `--background` | oklch(0.148 0.004 228.8) ≈ #090b0c | App background, message list, header, composer bar, full-screen viewer and guide |
| Secondary (30%) | `--muted` / `--card` | oklch(0.275 0.011 216.9) ≈ #22292b / oklch(0.218 0.008 223.9) ≈ #161b1d | Their bubbles (`Bubble variant="muted"`), composer input surface, quote blocks, reaction chip (`bg-muted`), notifications card (`Card`), drawers and popovers (`--popover` = card) |
| Your bubbles | `Bubble variant="tinted"` | `oklch(from var(--primary) 0.3 calc(c*0.4) h)` ≈ #4c1b22 | Every message you send. This is the preset's own rose tint of `--primary`, so your side reads rose without spending the solid accent. |
| Accent (10%) | `--primary` | oklch(0.455 0.188 13.697) ≈ #a50036 (text on it: `--primary-foreground` ≈ #fff1f2) | Only the elements listed below |
| Text | `--foreground` / `--muted-foreground` | ≈ #f9fbfb / ≈ #9ca8ab | Body text / status line, markers, placeholders, durations, quote snippets |
| Destructive | `--destructive` | oklch(0.704 0.191 22.216) ≈ #ff6467 | Failed-message state, discard-recording control, recording dot, error text only |

Accent (`--primary`, solid) is reserved for:
1. The composer Send button (`InputGroupButton` with `variant="default"`) and the mic button while it is recording or locked.
2. The primary button in the media preview drawer (count-aware "Send photo" / "Send 3 photos", etc.).
3. The primary button on the "Turn on notifications" card ("Enable notifications").
4. The voice-note play/pause button (`Button variant="default"` round, `size-11`).
5. The 2px left bar of a quote block, both inside a reply bubble and in the "Replying to" chip above the composer (`border-l-2 border-primary`).
6. The highlight shown when jumping to a quoted message: `ring-2 ring-primary` on the target bubble's content for 1.2 seconds, then fading out.
7. The selected reaction in the long-press reaction row (`bg-primary/20 ring-1 ring-primary` behind your current emoji).
8. Upload progress: `Spinner` with `text-primary` on tiles while uploading.

Do not use accent for: links, header icons, the attach button (`variant="ghost"`), menu items, the scroll-to-latest button (preset `secondary`), markers, or your bubbles (those use `tinted`).

Destructive is used only for:
- Failed bubbles: the footer row `WarningCircleIcon` plus "Not sent. Tap to retry." in `text-destructive`. The bubble itself stays `tinted` at `opacity-70`.
- Recording: the pulsing 8px recording dot (`bg-destructive`), and the locked-mode discard button (`Button variant="destructive" size="icon"`, `TrashIcon`).
- Error text in media tiles ("Couldn't load", "Couldn't process this video").

Waveform colors: played bars `bg-foreground` (fill `currentColor` with `text-foreground`), unplayed bars `text-foreground/30`. This works on both the tinted and the muted bubble.

## Screens and Interaction Contract

### 1. Chat screen (extends the Phase 1 `Shell`)

Structure, top to bottom: header (Phase 1) → optional notifications card → `MessageScroller` (flex-1) → reply chip (only while replying) → composer.

**Primary anchor:** the newest message at the bottom of the list, just above the composer. The list opens scrolled to it, and it is where the eye lands. The composer is secondary: it is always present but quiet (muted input surface, ghost attach and mic buttons). Accent appears in the composer only once there is something to send (the Send button) or while recording. The header is tertiary (`border-b`, 14px name, no accent).

**Header (Phase 1 D-11, extended)**
- Avatar + peer name, as in Phase 1. Under the name, a 12px `text-muted-foreground` subline appears only while the connection is not live: "Connecting…" (WS down for more than 2 seconds) or "Offline" (`navigator.onLine === false`). It is hidden when connected. The header stays `h-14`: name and subline stack in a `flex-col`.
- Menu (`DotsThreeVerticalIcon`): add "Notifications" (`BellIcon`) above the existing "Call test" and "Log out". It opens the Notifications drawer (section 6).

**Message list**
- `MessageScrollerProvider` > `MessageScroller` > `MessageScrollerViewport` > `MessageScrollerContent className="gap-4 px-4 py-8"`. Each item is a `MessageScrollerItem`.
- Your messages: `Message align="end"` + `Bubble variant="tinted" align="end"`. Their messages: `Message align="start"` + `Bubble variant="muted" align="start"`.
- **Markers (default, per discretion):** a day marker (`Marker variant="separator"`) before the first message of each local calendar day: "Today", "Yesterday", the weekday name for the last 7 days ("Tuesday"), otherwise "Mon, 3 Oct", with the year added when it is not the current year ("Mon, 3 Oct 2025"). Use `Intl.DateTimeFormat` in the device locale. A time marker (`Marker`, centered, no lines) appears before a message that comes more than 15 minutes after the previous one on the same day, formatted with the device locale's short time ("9:41 PM"). Bubbles show no per-bubble time.
- **Status line (D-03):** `MessageFooter` under **your most recent message only**: "Sending…" → "Sent" → "Read 9:41 PM" (time of the read event, short local time). It updates in place.
- **Failed message (D-03):** every failed bubble (not only the latest) shows a footer with `WarningCircleIcon` + "Not sent. Tap to retry." in `text-destructive`. Tapping the bubble or the footer retries with the same client message ID. On retry the footer returns to "Sending…".
- **Offline queue (default):** a message composed while offline renders immediately as a normal `tinted` bubble with the "Sending…" status. It flushes automatically on reconnect, in order. It becomes "failed" only after the server rejects it or after 3 automatic attempts once connected. Being offline alone never marks a message as failed.
- **Typing indicator (default):** a `muted` peer bubble at the end of the list containing three 8px dots (`size-2 rounded-full bg-muted-foreground`, `gap-1`) with a staggered opacity pulse (no animation under `prefers-reduced-motion`; the dots are static). `aria-label="{peer} is typing"`. It appears on a typing frame and disappears 5 seconds after the last one, or as soon as their message arrives. It does not push the list up if you are scrolled away from the bottom.
- **History (CHAT-02):** scrolling within one viewport of the top loads the next older page. While it loads, a `Marker` with `Spinner` + "Loading older messages…" sits at the top. On failure: "Couldn't load older messages. Tap to retry." When the first message is reached: a `Marker` "This is the beginning of your messages with {peer}."
- **First load:** 6 `Skeleton` bubbles alternating start and end, `h-10`, widths 40%/60%/50%. No spinner.
- **Scroll to latest:** `MessageScrollerButton direction="end"` (preset). When new messages arrived while you were scrolled up, show a `Badge` with the count over the button ("3"). Tapping it scrolls to the bottom and clears the count. When you are at the bottom, new messages auto-scroll into view. Sending anything (text, reply, photos/videos, voice note) always jumps to the newest message, even when you were scrolled up; only incoming messages bump the badge.
- **Resume / catch-up (CHAT-05):** silent. Missed messages are inserted in place with no spinner. The header subline shows "Connecting…" only if the reconnect takes more than 2 seconds.
- **Empty conversation:** the existing Phase 1 `Empty` block, centered in the list, with updated copy (see Copywriting). The composer stays visible and focusable.

**Gestures (D-01)**
- **Swipe right to reply:** active only when horizontal movement exceeds vertical movement and `dx > 8px`, so vertical scrolling always wins. The bubble follows the finger up to 72px. `ArrowBendUpLeftIcon` (`text-muted-foreground`, size 20) fades in to the left of the bubble, at full opacity by 56px. Releasing past 56px starts a reply (opens the reply chip and focuses the composer) and calls `navigator.vibrate?.(10)`. The bubble springs back in 200ms. Works on both your bubbles and theirs.
- **Long-press (450ms) or right-click/`contextmenu`** opens a controlled `Popover` anchored to the bubble (`side="top"`, aligned to the bubble's side). A light haptic fires on open. Content: a row of the six reactions **💕 💔 😋 😝 😘 😭** (D-04) as 44px round ghost buttons at 20px emoji size, with your current reaction highlighted (accent item 7). Then a `Separator`, then menu rows "Reply" (`ArrowBendUpLeftIcon`) and "Copy" (`CopyIcon`; shown only for messages with text or a caption). Pick a reaction → apply it and close. Pick your current reaction → remove it and close. Pick a different one → replace it. While the popover is open, the target bubble gets `ring-2 ring-ring/30`. Bubbles set `select-none [-webkit-touch-callout:none]` so iOS does not open its own callout. Tapping outside or pressing Escape closes the popover.
- **Reaction chip (D-04):** `BubbleReactions side="bottom"`, `align="start"` on your bubbles and `align="end"` on theirs (the chip sits on the inner corner). It shows each distinct emoji once, then a count if both of you picked the same one ("💕 2"). Tapping the chip opens the same long-press popover.

**Quoted reply (D-02, CHAT-09)**
- **Inside a reply bubble:** a quote block at the top of `BubbleContent`: `rounded-2xl bg-background/40 border-l-2 border-primary px-2 py-1` with the author on the first line (14px medium: "You" or the peer's name) and the snippet on the second (14px regular, `line-clamp-2`, `text-muted-foreground`). For media originals, the snippet is the media label ("Photo", "Video", "Voice note", "3 photos") and a 32px (`size-8`) rounded thumbnail sits at the right of the block (photos and videos only).
- **Tapping the quote** scrolls to the original and applies the accent highlight (item 6). If the original is not loaded yet, older pages are fetched until it is found while the top `Marker` shows "Finding message…". Then the list scrolls to it.
- **Reply chip above the composer:** the same quote block style, prefixed with "Replying to {name}" (12px meta) and followed by an `XIcon` ghost `icon-sm` button `aria-label="Cancel reply"`. Sending clears it.

**Composer**
- `InputGroup`: start addon `InputGroupButton` with `PlusIcon` (ghost, `size-11`, `aria-label="Attach photo or video"`). Then `InputGroupTextarea` (placeholder "Message {peer}", 16px, grows from 1 line to 6 lines / 144px, then scrolls). End addon: when the field is empty and nothing is attached, the mic button (`MicrophoneIcon`, ghost, `size-11`, `aria-label="Record voice note"`). Once text is entered it is replaced by Send (`PaperPlaneRightIcon`, `variant="default"` round, `size-11`, `aria-label="Send message"`) (D-10).
- **Enter key (default):** on coarse pointers (phones) Enter inserts a newline and only the Send button sends. On fine pointers (desktop) Enter sends and Shift+Enter inserts a newline.
- After sending, the field clears and keeps focus, so the keyboard stays up.
- While you type, a typing frame is sent at most every 3 seconds.

### 2. Sending photos and videos (D-05..D-09)

- **Attach** opens the hidden `<input type="file" accept="image/*,video/*" multiple>`. The OS picker provides Take Photo/Video, Photo Library and Files. There are no other buttons.
- **Preview drawer (D-06):** `Drawer` with a swipe handle, about 85dvh tall.
  - `DrawerTitle` = count label: "1 photo", "1 video", "3 photos", "2 videos", or "4 items" (mixed).
  - Body: one item → a large preview (`object-contain`, max 60dvh, `rounded-3xl`). Several items → an `AttachmentGroup` of `Attachment orientation="vertical"` thumbnails (`AttachmentMedia variant="image"`, video thumbnails overlaid with `VideoCameraIcon` + duration). Each has an `AttachmentAction` `XIcon` with `aria-label="Remove item"`. Removing the last item closes the drawer.
  - If a thumbnail cannot render (for example HEIC in Chrome), use `AttachmentMedia variant="icon"` with `ImageIcon`/`VideoCameraIcon` and the file name in `AttachmentTitle`.
  - Caption: `Textarea` with placeholder "Add a caption…", 16px, 1–4 lines.
  - `DrawerFooter`: the primary send button (`variant="default"`, full width, `size="lg"`) above the "Discard selection" button (`variant="ghost"`, full width). The primary label counts the items and uses the same nouns as the title: "Send photo", "Send video", "Send 3 photos", "Send 2 videos", "Send 4 items" (mixed). It updates live as items are removed. "Discard selection" is the Cancel action from D-06 under a specific label. Swiping the drawer down or tapping "Discard selection" discards the selection with no confirmation (nothing was sent).
  - **Primary anchor:** the preview itself (the large single preview, or the thumbnail strip), with the full-width accent send button as the one action that draws the eye. The caption field and "Discard selection" are visually secondary (ghost).
  - Limits are checked on pick, before the drawer opens: more than 10 items → keep the first 10 and show a toast. A video over 200 MB or over 3 minutes is removed from the selection and a toast is shown. If nothing is left, the drawer does not open.
- **Album bubble (D-07):** `Bubble variant="ghost"` (no padding), `w-72` (288px, capped at 80%), `rounded-3xl overflow-hidden`. The grid uses a 4px gap:
  - 1 item: natural aspect ratio clamped between 3:4 and 4:3, full width.
  - 2 items: two square tiles side by side.
  - 3 items: the first tile is full width at 2:1, then two squares below it.
  - 4 items: 2×2 squares.
  - 5–10 items: 2×2 showing the first four, with the fourth tile overlaid by `bg-background/60` and "+N" (20px, medium) centered.
  - Tiles use the server thumbnail (`object-cover`). A caption, if present, renders under the grid in a regular `tinted`/`muted` `BubbleContent` in the same `Bubble`.
  - Video tiles: poster image, a centered 40px round `bg-background/60` button with `PlayIcon` (fill), and the duration bottom-right ("0:42", 12px `tabular-nums`, `bg-background/60 rounded-full px-2`).
  - Tapping any tile opens the viewer at that item.
- **Sending state:** the bubble appears immediately using local object URLs. Each uploading tile shows `bg-background/40` with a centered `Spinner` (`text-primary`) and the percentage ("45%", 12px). The message status reads "Sending…".
- **Video processing (D-08):** after upload, video tiles show a muted surface with `Spinner` + "Processing…" (12px) until the server's ready event delivers the poster. The recipient receives the message once the upload completes and sees the same processing tile. Images show as soon as the display copy exists.
- **Failures:** if an upload fails, the message becomes failed ("Not sent. Tap to retry."; retry re-uploads only the items that failed). If a transcode fails, the tile shows `VideoCameraIcon` + "Couldn't process this video" (12px, `text-destructive`) to both people. If an image fails to load, the tile shows `ImageBrokenIcon` + "Couldn't load", and tapping it retries the load.
- **Full-screen viewer (MDIA-02):** `Dialog` styled full-screen (`fixed inset-0 max-w-none rounded-none bg-background p-0`) with a `Carousel` covering the album's items.
  - Top bar (`h-14`, safe-area top): close button (`XIcon`, ghost, `aria-label="Close viewer"`) on the left and the counter "2 / 5" (12px) in the center. The counter is hidden for single items.
  - Images use the display copy, `object-contain`, filling the viewport.
  - Videos use `<video controls playsInline preload="metadata" poster>` at `object-contain`. They do not autoplay.
  - If an image or video fails to load in the viewer, that slide shows a centered `ImageBrokenIcon` (or `VideoCameraIcon`) with "Couldn't load" (14px, `text-muted-foreground`). Tapping it retries. The other slides and the counter are unaffected.
  - Swipe left/right moves between items. Closing uses the X button or Escape. Arrow keys work on desktop. The caption, if present, shows at the bottom (16px, `text-foreground`, max 3 lines, `bg-background/60`).

### 3. Voice notes (D-10..D-12)

- **Hold to record:** pressing and holding the mic starts recording after the permission prompt (the first time only). While recording, the composer row is replaced by: the recording dot (8px, `bg-destructive`, pulsing unless reduced motion is set), a timer ("0:07", 16px `tabular-nums`), and the hint "Slide to cancel" with `CaretLeftIcon` (14px, `text-muted-foreground`). The mic button stays under the finger, switches to `variant="default"` (accent), and scales to 1.25. Above the mic sits a pill (`bg-muted rounded-full`, 44px wide) with `LockSimpleIcon` over `CaretUpIcon`.
  - Release → send.
  - Slide left more than 96px → cancel and discard, with a haptic.
  - Slide up more than 64px → lock.
- **Tap to lock:** a tap shorter than 300ms on the mic starts recording directly in locked mode (D-10, "or tap").
- **Locked mode:** the row shows the discard button (`TrashIcon`, `variant="destructive"`, `aria-label="Discard recording"`), the recording dot and timer, and the Send button (accent, `aria-label="Send voice note"`). Discarding is immediate, with no confirmation.
- **Too short:** a hold released between 300ms and 1s discards the recording and shows a toast.
- **No length limit (D-11).** The timer keeps counting past 59:59 as "1:00:00".
- **Voice-note bubble:** `Bubble variant="tinted"|"muted"` with `BubbleContent` as a row, `w-72` (288px, capped at 80%): play/pause button (accent, round `size-11`) | waveform (flex-1, 32px tall, 40 bars) | duration (12px `tabular-nums`, `text-muted-foreground`).
  - The duration shows the total while idle and elapsed time while playing or paused mid-way.
  - The waveform is `role="slider"`, `aria-label="Seek voice note"`, `aria-valuemin=0`, `aria-valuemax={durationSec}`, `aria-valuenow`, `aria-valuetext="0:12 of 0:42"`. Tap or drag anywhere on it to seek (pointer capture). The keyboard arrow keys move ±5 seconds.
  - Starting a voice note pauses any other voice note or video that is playing. When the note reaches the end, it resets to the start and shows the total duration again.
  - Loading state: the play button shows a `Spinner` until the audio can play. If loading fails, the play button becomes `WarningCircleIcon` and the duration area shows "Couldn't load" (12px destructive). Tapping it retries.

### 4. Add to Home Screen guide (SHEL-03, D-16)

## Accessibility and Motion

- Every icon-only button has an `aria-label`, as listed above.
- The message list region has `aria-label="Messages with {peer}"`. New incoming messages are announced through a visually hidden `aria-live="polite"` node as "{peer}: {text or media label}".
- Long-press actions are also reachable without gestures: the bubble is focusable (`tabIndex=0`) and Enter/`contextmenu` opens the same popover. Reply is available in the popover, so swiping is never the only path.
- `prefers-reduced-motion`: no typing-dot pulse, no recording-dot pulse, no bubble spring (snap back instantly), and the jump highlight shows with no fade.
- Focus rings come from the preset (`focus-visible:ring-3 ring-ring/30`). Do not remove them.
- Contrast: body text `--foreground` (≈#f9fbfb) on `tinted` (≈#4c1b22) and `muted` (≈#22292b) bubbles is well above 4.5:1. Meta text uses `--muted-foreground` on `--background` only.
